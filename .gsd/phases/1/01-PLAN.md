# Phase 1: Foundation & Auth Plan

## Objective

Set up the core Next.js project structure, Shadcn UI library, and Supabase Authentication with custom host-only login forms.

## Tasks

- [ ] **Setup-01**: Initialize Next.js project (App Router, Tailwind, TS).
- [ ] **Setup-02**: Install and configure Shadcn UI.
- [ ] **Auth-01**: Configure Supabase client and environment variables.
- [ ] **Auth-02**: Implement custom Login & Register forms using Shadcn components.
- [ ] **Auth-03**: Setup Middleware to protect `/dashboard` routes.
- [ ] **UI-01**: Define global retro/nostalgic color palette and typography.

## Verification

- [ ] Project builds successfully.
- [ ] User can register and login as a host.
- [ ] Unauthorized users are redirected from `/dashboard` to `/login`.
