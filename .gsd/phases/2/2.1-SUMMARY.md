# Plan 2.1 Summary: Schema & Upload Refactor

## Changes Made

### Database

- Created migration `supabase/migrations/20260304000000_add_media_type.sql` to add `media_type` and `mime_type` columns to the `photos` table.
- Added CHECK constraint for `media_type` in `('photo', 'video')`.

### Backend (Server Actions)

- Refactored `uploadPhotoToTelegram` to `uploadMediaToTelegram` in `src/lib/telegram/actions.ts`.
- The action now accepts `mediaType` and `mimeType` via `FormData` and persists them to Supabase.
- Maintained `sendDocument` as the storage method for all media to ensure original quality.

### Frontend

- Updated `src/app/[eventCode]/page.tsx` (Bulk Upload) to use the new `uploadMediaToTelegram` action.
- Updated `src/app/[eventCode]/camera/page.tsx` (Camera Capture) to use the new action.

## Verification

- Verified code changes via grep and file inspection for all call sites.
- Confirmed that existing photo upload paths now explicitly send `mediaType: 'photo'`.
